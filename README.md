# ☕ Coffee Shop Sales Analysis (SQL + Power BI)

## 📌 Overview  
This project demonstrates an end-to-end data analytics workflow for a coffee shop sales dataset. SQL was used to clean and prepare the raw data by fixing date and time formats, correcting column issues, and ensuring consistency for analysis. The cleaned data was then analyzed and visualized using Power BI to create an interactive dashboard.

---

## 🎯 Objectives  
- Clean and standardize raw sales data using SQL  
- Analyze sales trends and performance  
- Identify top-selling products and peak sales hours  
- Compare weekday and weekend sales patterns  
- Visualize insights in an interactive Power BI dashboard  

---

## 🛠 Tools Used  
- SQL (MySQL) – Data cleaning and analysis  
- Power BI – Dashboard and visualization  
- Excel / CSV – Dataset storage  

---

## 📊 Key Analysis  
- Total sales and order tracking  
- Month-over-month sales comparison  
- Product category and product type performance  
- Daily and hourly sales trends  
- Store location performance  
- Weekday vs weekend sales analysis
